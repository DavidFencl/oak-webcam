# Glossary

- OAK4 / RVC4: device family capable of running standalone apps.
- DepthAI v3: SDK for defining the camera processing pipeline.
- OAK App: container packaged using oakapp.toml and oakctl.
- UVC: USB Video Class; exposes a device as a standard USB webcam.
- Virtual webcam: host software presenting a video source to camera applications.
- Holistic recording: capture of pipeline sources for replay; not a screenshot.
- Proof: frames observed by the consumer, not merely a running process.
